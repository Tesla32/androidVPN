# Cloavy VPN v7 Product Beta

Версия v7 продолжает рабочую ветку Android-приложения с backend auto-provision.

## Что добавлено

- onboarding на 3 экрана;
- карточка тестового доступа;
- отображение срока действия доступа, если backend его возвращает;
- более понятный статус доступа в настройках и на экране статуса;
- подготовка интерфейса к подпискам;
- сохранены 4 темы оформления;
- сохранены RU / EN;
- сохранена рабочая кнопка подключения VPN.

## Проверка

1. Собрать APK через Android Studio.
2. Установить на Android.
3. Проверить onboarding.
4. Нажать «Активировать».
5. Убедиться, что backend создал клиента в wg-easy.
6. Проверить IP.
