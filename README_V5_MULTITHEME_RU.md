# Cloavy VPN v5 Multitheme

Версия v5 добавляет систему визуальных тем без изменения рабочей VPN-логики.

## Что внутри

- AutoProvision backend сохранен.
- VPN подключается одной кнопкой.
- Добавлен выбор 4 тем:
  - Степной
  - Брутальный
  - Минимал
  - Игровой
- По умолчанию выбрана тема Минимал.
- Выбор темы сохраняется локально на устройстве.
- RU / EN сохранены.

## Где менять тему

Настройки -> Тема оформления.

## Как собрать APK

Android Studio -> Build -> Build Bundle(s) / APK(s) -> Build APK(s).

APK будет в app/build/outputs/apk/debug/app-debug.apk.
