# Cloavy VPN Android AutoProvision v3

Эта версия работает без ручного импорта QR-кода или .conf файла.

Пользовательский сценарий:
1. Пользователь устанавливает APK.
2. Открывает Cloavy VPN.
3. Нажимает «Защитить».
4. Cloavy обращается к backend на VPS.
5. Backend создает или возвращает персональный WireGuard-доступ для устройства.
6. Android показывает системное VPN-разрешение.
7. VPN включается.

Тестовый backend: http://169.58.97.115:8080
Тестовый токен в приложении: cloavy_test_2026_token

Важно: это тестовая версия. Для публичного распространения нужен HTTPS, нормальная авторизация, лимиты, платежи и защита API.
