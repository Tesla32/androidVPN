# Cloavy VPN v4 Cyberpunk

Версия v4 сохраняет рабочую механику AutoProvision и обновляет визуал приложения под игровой киберпанк-концепт.

## Что изменено

- Главный экран переделан в формате cyber shield.
- Добавлена нижняя навигация: Главная, Режимы, Серверы, Статус, Настройки.
- Добавлены продуктовые статусы без технических слов для пользователя.
- Сохранено реальное подключение через backend и WireGuard tunnel library.
- Сохранена поддержка RU / EN.
- Добавлены экраны режимов защиты, серверов, статуса и настроек.
- Версия приложения обновлена до 0.4.0-cyberpunk.

## Важно

Backend должен быть доступен по адресу:

http://169.58.97.115:8080

Тестовый токен должен совпадать с токеном в backend:

cloavy_test_2026_token

## Как собрать APK

1. Распаковать проект в папку без русских букв, например:

C:\Dev\CloavyVPN_AndroidStudio_V4_Cyberpunk

2. Открыть папку проекта в Android Studio.
3. Дождаться Gradle Sync.
4. Выполнить:

Build -> Build Bundle(s) / APK(s) -> Build APK(s)

5. APK будет находиться здесь:

app\build\outputs\apk\debug\app-debug.apk

## Как тестировать

1. Установить APK на Android-телефон.
2. Отключить другие VPN.
3. Открыть Cloavy VPN.
4. Нажать Активировать.
5. Подтвердить системное VPN-разрешение Android.
6. Проверить, что в wg-easy появился новый клиент cloavy-auto-...
7. Проверить внешний IP.

## Что пока тестовое

- Список серверов, кроме Auto / Contabo EU, пока визуальный.
- Режимы защиты пока меняют UI-сценарий, но не серверную маршрутизацию.
- Трафик в статусе пока не считается точно.
- Backend пока работает по HTTP и тестовому токену.
