# Cloavy VPN Android Mock v1

Нативный Android-проект для открытия в Android Studio.

Это mock-приложение. Реального VPN-подключения пока нет. Кнопка защиты меняет только demo-статус.

## Что внутри

- Kotlin + Jetpack Compose.
- 4 кастомные темы внутри приложения:
  - Степной стиль: песок, конь степи, цифровой оберег.
  - Брутальный стиль: темный уличный стиль, кислотный акцент, дерзкие карточки.
  - Минимал: чистый premium-стиль, тема по умолчанию.
  - Игровой: неон, киберпанк, быстрый ритм.
- RU / EN переключатель.
- Главная, режимы, серверы, Premium, настройки, выбор темы.
- Mock Free / Premium.
- Mock серверы и режимы защиты.

## Как открыть

1. Распакуй архив.
2. Открой папку `CloavyVPN_AndroidStudio_v1` в Android Studio.
3. Дождись Gradle Sync.
4. Выбери Android Emulator или реальный Android-телефон.
5. Нажми Run.

## Важно

В проекте нет Gradle Wrapper, чтобы не тащить неподтвержденные бинарные файлы. Android Studio сможет использовать встроенный Gradle. Если Android Studio предложит создать wrapper, можно согласиться.

## Если Gradle Sync ругается

Проверь:

- Android Studio обновлена.
- Установлен Android SDK 35.
- Установлен JDK 17.
- Есть интернет для загрузки Gradle-зависимостей.

## Package name

`app.cloavy.vpn`

Для тестов можно оставить как есть. Для публикации в Google Play потом проверим уникальность package name и добавим dev/prod flavors.
