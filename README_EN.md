# Cloavy VPN Android Mock v1

Native Android Studio project.

This is a mock app. There is no real VPN tunnel yet. The protection button changes only demo connection status.

## Included

- Kotlin + Jetpack Compose.
- 4 custom in-app themes:
  - Steppe: sand, steppe horse, digital amulet.
  - Brutal: dark street style, acid accent, bold cards.
  - Minimal: clean premium style, default theme.
  - Gaming: neon, cyberpunk, fast rhythm.
- RU / EN switcher.
- Home, modes, servers, Premium, settings, theme picker.
- Mock Free / Premium.
- Mock servers and protection modes.

## How to open

1. Unzip the archive.
2. Open `CloavyVPN_AndroidStudio_v1` in Android Studio.
3. Wait for Gradle Sync.
4. Select Android Emulator or a real Android device.
5. Press Run.

## Important

The project does not include Gradle Wrapper to avoid shipping unchecked binary files. Android Studio can use bundled Gradle. If Android Studio suggests creating a wrapper, you can accept it.
