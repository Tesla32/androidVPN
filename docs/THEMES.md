# Cloavy VPN themes

Default theme: Minimal.

Theme IDs:

- `steppe`: Kazakh steppe inspired visual language.
- `brutal`: dark street and rebel visual language.
- `minimal`: clean premium neuro style, default.
- `gaming`: neon cyberpunk gaming visual language.

Each theme changes:

- background gradient;
- panel colors;
- accent colors;
- hero symbol;
- connection orb details;
- card mood;
- theme description;
- warning and premium visual tone.
